## Implemented contract

- Native choice requires current exposed tool plus action/mode permission.
  Failure falls back once with the same identity and three approval options.
- Explicit user events bind gate, artifact/revision, owner/change, scope and
  semantic/localized option mapping. Spec approval does not approve plan;
  ambiguous numbers, silence, visual feedback and recommendations never approve.
- One `resolveFinish` path serves generic/NestJS/AI-agent, Angular, Next.js and
  delegated completion. Workers stop at unit evidence; the integration owner
  runs final finish. Existing policy removes repeated questions.
- Skip, Analyze, explicit Apply, read-only review, bounded review-and-repair,
  skip-review and defer have distinct behavior. Protected simplify boundaries,
  owner/tier checks, required tests and acceptance criteria remain gates.
- Actual repository snapshots and command receipts bind content, cwd, owner,
  scope and result. Review assessment digests cannot be swapped after proof.
  Writes stale affected evidence at the same HEAD. Final commands cover the
  full scope; hook writes cannot escape exact authority, including directories.
- Spec/plan, stack callers, Review/Repair/Docs/Ship and portable handoff use the
  shared continuation. Tests consume payload examples from canonical docs.

remain immutable; no bulk migration is performed.

inspection and deterministic fixtures do not certify a live native UI, provider,
