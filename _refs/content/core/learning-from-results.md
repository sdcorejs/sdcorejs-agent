# Learn from real feedback

Separate three records: observed edit/performance, proposed interpretation and
accepted rule. For an edit quote the before/after pattern and scope; one removed
joke does not prove the author never wants humor. Ask only if persistence or a
material voice change is requested and unresolved.

For analytics record period, sample/post count, numerator/denominator, audience,
channel and organic/paid context when available. Compare comparable posts and
state confounders such as spend, seasonality and distribution. Missing exposure
counts limit rate comparisons. One high-view post supports an observation,
not a causal claim about posting time, hooks, hashtags or the algorithm.

Suggest one bounded next experiment with a success signal and review window.
No performance guarantee. Reuse actual feedback in the current draft; persist
only accepted rules with profile owner/path authority, keeping personal and
brand records separate.
