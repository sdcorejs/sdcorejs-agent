# SDCoreJS Agent for Claude Code

This plugin bundles 25 engineering skills for planning, implementation, testing
and review. Extract the archive and start Claude Code with `claude --plugin-dir
<extracted-folder>`. At session start the bundled hook introduces the pack.
Ask Claude Code to use `sdcorejs-explore` for a read-only repository summary.
The shared references travel with the skills. Optional local helpers may
require Node.js or project tooling. See the [installation guide](https://github.com/sdcorejs/sdcorejs-agent/blob/main/docs/INSTALLATION.md).
