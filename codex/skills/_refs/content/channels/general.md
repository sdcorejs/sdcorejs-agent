# Additional channels

Identify the actual consumption pattern: feed text, search, community thread,
professional discussion or video. Adapt structure, voice and CTA to the supplied
audience and known destination. If limits/features affect the deliverable, use
dated primary platform evidence; otherwise provide a portable draft with a
labeled assumption. Never fabricate a specialist channel rule.

To add a channel, create one independent reference with applicability,
exclusions, provenance, review date and refresh triggers; register it in catalog
and add selection/no-match tests. Do not create skills per channel/domain pair.
