# Carousel

Give the sequence one promise and make each slide advance it: opening,
context/problem, useful steps/examples and takeaway. Keep one main idea per
slide, meaningful order and readable text. Supply slide title/body plus optional
visual/alt-text direction; label this as a content outline until assets exist.
Check actual channel constraints before final asset production, not from a
universal slide-count rule. Keep necessary claim qualifiers readable.
