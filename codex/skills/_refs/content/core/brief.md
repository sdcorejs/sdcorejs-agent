# Resolve brief

Use existing evidence to fill identity, audience, objective, message, channel,
format, domain, sources and constraints. Mark what is confirmed versus assumed.
Personal: whose perspective and what experiences have they actually supplied?
Product: which product, audience problem, supported benefit and desired action?
Ask a compact question only for a missing fact that materially changes the copy.
For a campaign, also establish deliverable count, resources, review owner,
timeframe and success signal. Drafting a calendar is not scheduling posts.

Example brief: personal narrator; weekend walkers; inspire a saved itinerary;
Facebook text; travel; supplied route facts; no firsthand visit; warm practical
voice. This is sufficient for one caption without an engineering plan.
